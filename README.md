# Poker Dice - Android App

This is the mobile client for my university project, a digital version of the *Poker Dice* game. It was built to connect directly to the backend API developed in my Web Application Development (DAW) course.

## Tech Stack

To build this native mobile application, the following tools were used:

**Mobile (Android):**
* **Kotlin**
* **Jetpack Compose:** For building a modern, declarative UI.

**Backend Integration:**
* Consumes the REST API and Server-Sent Events (SSE) from the [Poker Dice Backend](https://github.com/nunesandre13/daw-poker-dice).
